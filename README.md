# مخزوني

تتبّع شراء وبيع المنتجات بالصور (PWA): صوّر منتج، سجّل سعر الشراء، وبعدين سعر البيع لما ينباع. ملخص يومي بالربح والخسارة، ورأس المال الحالي (تكلفة المخزون الغير مباع).

## التشغيل محليًا

```
npx serve .
```
أو
```
python -m http.server 8080
```

لا تفتح بـ `file://` مباشرة.

## التثبيت على آيفون

1. افتح رابط النشر **في Safari**.
2. زر المشاركة ← **أضف إلى الشاشة الرئيسية** ← إضافة.
3. **افتح التطبيق دائمًا من الأيقونة الجديدة** — لا من رابط Safari — عشان بياناتك (الصور والمنتجات) تضل محفوظة بأمان على المدى الطويل (iOS يعفي التطبيقات المثبّتة من الشاشة الرئيسية من حذف البيانات بعد 7 أيام، لكن هذا الإعفاء خاص بوضع التشغيل المستقل فقط).

## التخزين

الصور والمنتجات محفوظة محليًا عبر IndexedDB (`js/db.js`) — ما تُرسل لأي خادم. الصور تُضغط تلقائيًا (أقصى بُعد 800px) قبل الحفظ لتوفير المساحة.

## بنية الكاش (service worker)

عند تعديل أي ملف مُخزَّن مسبقًا، ارفع رقم `CACHE_VERSION` في `service-worker.js` قبل النشر.
